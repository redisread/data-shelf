# data-shelf 产品设计

当前处于需求访谈阶段，尚未确认完整设计或开始应用实现。

## 已确认

- 使用 mygo 开发 macOS 桌面应用，内容仅保存在本地，不考虑同步。
- 使用普通本地文件和真实嵌套文件夹组织资料，支持 Finder 查看、复制和备份。
- 新建文件和文件夹支持快速输入名字，不增加确认弹窗。
- 文件内容自动保存；合法 JSON 自动识别，格式错误或不完整的内容仍保留原文并提示错误；JSON 格式化为独立操作。
- JSON 和 Markdown 支持任意文本选区标记和一条可编辑评论，首版不加入多人回复或讨论串。
- 文件可继续编辑；修改后尽量保留标记关联，原文删除或无法可靠定位时显示为待重新定位，不猜测绑定。
- 首版目标为单文件 10 MB 内、总计数千份文件；超限明确提示，避免直接加载导致界面卡顿。
- Markdown 支持渲染；架构需允许后续扩展文件类型。

## 待细化

- 资料目录默认位置、元数据位置及导入方式。
- 命名、扩展名与格式识别的优先级。

- 应用内和 Finder 中修改文件时的行为。
- 检索、文件管理和窗口布局的首版范围。
- mygo 原生界面路线及本机构建验证。
